IMPORTANT!

To install this mod, put "JumpSpaceBalance.dll" in the game directory, and rename it to "winhttp.dll". If you don't rename it,
the mod will NOT load and will do nothing.

If "winhttp.dll" happens to be taken by another mod, use one of the following instead:
- "dxgi.dll"
- "version.dll"

Note that if you have Melon Loader (mod manager for Jump Space) installed, then this is the wrong version of the JumpSpaceBalance
mod. You need to go back and download the Melon version of this mod instead.

Happy hunting!
