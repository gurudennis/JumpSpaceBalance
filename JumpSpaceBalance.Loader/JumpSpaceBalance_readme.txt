IMPORTANT!

First and foremost, ensure that you have Melon Loader (mod manager for Jump Space) installed.

To install this mod, unpack all of the contents of this archive into the game directory, and select Overwrite if prompted.
Do NOT rename any files or directories.

Note that if you don't have Melon Loader installed and you don't wish to install it, then this is the wrong version of the
JumpSpaceBalance mod. You need to go back and download the Standalone version of this mod instead.

Happy hunting!
